# raptor-labs

Company site for Raptor Labs (raptorlabs.co). Vite + React, deployed on Vercel.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

- `src/App.tsx` page composition
- `src/scroll-scrub-scenes.ts` scroll film chapters (copy + clip paths)
- `src/components/site/` page sections and `site.css` (brand tokens and styles)
- `src/components/scroll-scrub/` scroll-driven video engine
- `public/assets/` film clips, icons, images
- `design-brief.md` design decisions
